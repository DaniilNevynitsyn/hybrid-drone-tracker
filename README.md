# Hybrid Drone Object Tracker (NanoTrack + YOLOv11 + GMC)

This repository contains the source code for a highly optimized, hybrid visual object tracking system designed for unmanned aerial vehicles (UAVs) and edge platforms. The system was developed as part of a Bachelor's thesis research project to solve the fundamental problem of tracker "drift" under extreme conditions (vibrations, occlusions, and dynamic backgrounds).

## Key Features
- **Hybrid Architecture**: Combines the high-speed processing of Siamese Neural Networks (NanoTrack) with the precision of deep object detectors (YOLOv11n).
- **Snap-back Correction**: Uses YOLOv11 and HSV Color Histogram Re-Identification (Re-ID) to intelligently recover lost targets and resolve object collisions.
- **Global Motion Compensation (GMC)**: Implements RANSAC-based homography to cancel out drone ego-motion and camera vibrations.
- **EMA-Filter**: Smooths the tracking trajectory, minimizing Center Location Error (CLE).
- **Edge-Ready**: Optimized for CPU and NPU (Edge TPU, Hailo-8L) execution without the need for expensive server-grade GPUs.

## Installation

1. Clone the repository:
```bash
git clone https://github.com/DaniilNevynitsyn/hybrid-drone-tracker.git
cd hybrid_drone_tracker
```

2. Create a virtual environment (optional):
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. Install the required dependencies:
```bash
pip install -r requirements.txt
```

*Note: The project uses ONNX Runtime. For execution on Edge devices, ensure you install the appropriate hardware-accelerated version of ONNX Runtime (e.g., OpenVINO, TensorRT).*

##  Usage

1. Place your test video in the `videos/` folder and name it `sample_video.mp4` (or change the path in `hybrid_tracker.py`).
2. Run the tracker:
```bash
python hybrid_tracker.py
```

**Command-line Arguments:**
- `--source`: Path to the video file OR camera ID (e.g., `0` for webcam). Default: `videos/sample_video.mp4`.
- `--freq`: Frequency of YOLO calls in Hybrid mode (e.g., `10` means run YOLO every 10 frames). Default: `10`.

*Example: Using a webcam and calling YOLO every 5 frames:*
```bash
python hybrid_tracker.py --source 0 --freq 5
```
3. **How to use the GUI**:
   - The application will start in **MOT MODE (Searching)**.
   - You will see bounding boxes generated by the YOLO detector.
   - **Click** on any bounding box to lock onto a YOLO-detected target.
   - **Click and Drag** to draw a custom manual bounding box around any object on the screen. 
   - If you want to reset and pick a new target, click anywhere on the screen outside of the target box.
   - Press `q` to quit the application.
